    #Anahtarlar

    Tür Ad Kolonlar
    PRIMARY KEY TBLPOSPARAM_PKEY SUBE_KODU+POS_TIPI
    FOREIGN KEY TBLPOSPARAM_FKEY SUBE_KODU

    Şema dokümanı yabancı anahtarların hangi tabloya bağlandığını vermiyor; yalnızca bu tablodaki kolonları listeliyor.
