    #JSON örnekleri

    Gövdeler Logo'nun Postman örneklerinden ve yardım sayfalarından derlenmiştir. Hepsi POST ile, Content-Type: application/json ve Authorization: Bearer <token> başlıklarıyla gönderilir. Tarih biçimi yyyy-MM-dd HH:mm:ss ya da ISO 8601'dir.

    Ortak üst düzey alanlar (birçok gövdede):

    Alan Anlam
    TransactSupport Transaction desteği; OpenTransaction ile birlikte kullanılır
    MuhasebelesmisBelge Muhasebeleşmiş belge işareti
    OnayTipi, OnayNum Onay akışı alanları ("A", 0)

    #ItemSlips alanları

    Üst düzey: FaturaTip, Seri, FatUst, Kalems, Tahsilats, EIrsEkBilgi, hesaplama bayrakları: KosulluHesapla, FiyatSistemineGoreHesapla, StokKartinaGoreHesapla, SeriliHesapla, MaliyetTipineGoreHesapla, OtoIskontoGetir, OtoVadeGunGetir, OtomatikIslemTipiGetir, OtomatikOdemeKoduGetir, RiskKontrol, BaglantiKontrol, ProjeKodKontrol, SonNumaraYazilsin, KayitliNumaraOtomatikGuncellensin, EPostaGonderilsin; ayrıca TransactSupport, MuhasebelesmisBelge, Use64BitService.

    FatUst: Sube_Kodu, CariKod, CARI_KOD2, FATIRS_NO, GIB_FATIRS_NO, Tarih, ENTEGRE_TRH, FIYATTARIHI, KOSULTARIHI, DovBazTarihi, FiiliTarih, SIPARIS_TEST, Tip, TIPI, KOD1, KOD2, PLA_KODU, Proje_Kodu, KOSULKODU, ODEMEGUNU, KDV_DAHILMI, EKACK1…EKACK16, AMBHARTUR, GCKOD_GIRIS, GCKOD_CIKIS, TopDepo, TopGirDepo, OnayTipi, OnayNum, EFatOzelKod, EIrsaliye, EIrsEkBilgi, Faturalanmayacak, toplam alanları.

    Kalems[]: StokKodu, STra_GCMIK, STra_GCMIK2, STra_BF, STra_NF, STra_SatIsk…STra_SatIsk6, STra_KDV, STra_DOVTIP, STra_DOVFIAT, Olcubr, DEPO_KODU, Gir_Depo_Kodu, MuhasebeKodu, ReferansKodu, ProjeKodu, Plasiyer_Kodu, STra_SIPNUM, Stra_OnayTipi, IadeFaturaNo, IadeFaturaTarihi, KalemSeri[], SatirBaziAciks.

    Tam ve sürümünüze uygun liste: GET api/v2/definitions/ItemSlips.

    Enum'lar sayı ya da ad olarak. Örneklerde Tip: 0, TIPI: 2 gibi sayılar da, C# istemcisinde ftSFat, ft_Acik gibi adlar da kullanılır. Sayı–ad eşlemesi için Kimlikler ve enum'lar.

    #Fatura hesaplama

    POST api/v2/ItemSlips/Calculate: gövde fatura ile aynıdır, kayıt yapmaz, toplamları döndürür. Hesaplanmış net fiyat YedekKalems içindedir; yanıttaki FATIRS_NO kullanılmamalıdır.

  "CustomerCode": "120-01-001",
  "ItemSlip": {
    "FaturaTip": "ftSFat",
    "Seri": "ABC",
    "KayitliNumaraOtomatikGuncellensin": true,
    "EPostaGonderilsin": false,
    "RiskKontrol": false,
    "KosulluHesapla": false,
    "FatUst": {
      "FATIRS_NO": "ABC024000000123",
      "GIB_FATIRS_NO": "ABC2024000000123",
      "CariKod": "120-01-001",
      "Tarih": "2024-06-01 00:00:00",
      "TIPI": 2,
      "KDV_DAHILMI": false

    ItemSlip, hedef belgenin başlığını ve bayraklarını taşır. IrsToFat aynı yapıdadır (DocumentType irsaliye tipi). ItemSlip.FatUst.FATIRS_NO zorunludur.     #Cari hareket

    POST api/v2/ARPTransactions

    {
  "TransactSupport": true,
  "MuhasebelesmisBelge": false,
  "SilmeIcinGerekliSahalar": "INC_KEY_NUMBER",
  "SonKayitNoAl": false,
  "Sube_Kodu": 0,
  "CARI_KOD": "120-01-999",
  "Tarih": "2024-06-01",
  "Vade_Tarihi": "2024-07-01",
  "Belge_No": "DKT000000000001",
  "Aciklama": "Açılış",
  "Hka": "A",
  "Borc": 1.0,
  "Alacak": 0.0,
  "DOVIZ_TURU": 0,
  "Doviz_Tutar": 0.0,
  "Hareket_Turu": "A",
  "Proje_Kodu": "1",
  "OnayTipi": "A",
  "OnayNum": 0
}

    SilmeIcinGerekliSahalar silmede kullanılacak anahtarı (INC_KEY_NUMBER) belirtir. Kaydın kimliğini almak için SonKayitNoAl: true gönderin; false ise Inc_Key_Number 0 döner ve kaydı silemezsiniz. Hka zorunludur, denemede A çalıştı. Hka ve Hareket_Turu ayrı alanlardır; Hareket_Turu için A ve D denendi, tabloda A, B, C, D, E, G, H, I, J, K görülür (Netsis kasa kaydı için D, çek için G yazar). Tam liste belgelenmemiştir (TBLCAHAR.HKA açıklamasına göre K "öncelikli kapatılmış").

    Cari kartı güncellemede PUT api/v2/ARPs/{CARI_KOD} kısmi gövde kabul eder: yalnız gönderilen CariTemelBilgi alanları değişir.

  "StokEkBilgi": { "Stok_Kodu": "HAMMADDE-1" }

    Payda_1 ve Payda2 verilmezse kayıt CC_PAYDA_1 kısıtına takılır. Bu kartın faturada kullanılması için MUH_DETAYKODU da tanımlı olmalıdır.     #Kasa

    POST api/v2/SafeDeposits

    {
  "KsMas_Kod": "01",
  "Tarih": "2024-06-01",
  "Fisno": "KSA000000000001",
  "IO": "G",
  "Tip": "C",
  "Cari_Muh": "C",
  "Kod": "120-01-999",
  "Aciklama": "Tahsilat",
  "Tutar": 45.0,
  "DovizTut": 0.0,
  "Kur": 0.0,
  "Sube_Kodu": 0,
  "Plasiyer_Kodu": "01",
  "Proje_Kodu": "1",
  "OnayTipi": "A",
  "OnayNum": 0
}

    IO: G gelir (tahsilat) / C gider (ödeme). Tip: C cari, F fatura, M muhtelif… Cari_Muh: Kod alanı cari mi (C) muhasebe mi (M). Proje_Kodu ve Plasiyer_Kodu zorunludur (Hata Kodu 203); plasiyer için carinin PLASIYER_KODU değeri kullanılabilir. Yanıttaki Sira kaydın kimliğidir (TBLKASA.SIRA): DELETE api/v2/SafeDeposits/{Sira} kasa kaydını ve Netsis'in onunla birlikte yazdığı cari hareketi siler. Denemede Fisno gönderilmedi; numaranın nasıl üretildiği doğrulanmadı.

    POST api/v2/CheckAndPNotesMain

    {
  "Tip": "csMCEK",
  "CekSenEvrakKaydetmeTip": "ektCekSenAlma",
  "Plasiyer_Kodu": "01",
  "Evraklar": [{
    "Sube_Kodu": 0,
    "SC_NO": "CEK-0001",
    "SC_GIRTRH": "2024-06-01", "VADETRH": "2024-07-01", "SC_ODETRH": "2024-07-01",
    "SC_VERENK": "120-01-999",
    "SC_ABORCLU": "Veren kişi", "SC_BANKNO": "0001", "CEK_SUBE": "Merkez", "C_NUMARA": "12345678",
    "AS_C": "A", "SC_SONDUR": "P", "SC_YERI": "P",
    "Tutar": 456.0,
    "DOVTIP": 0, "DOVTUT": 0.0,
    "GIRILDIGIYER": 2,
    "Plasiyer_Kodu": "01",
    "Proje_Kodu": "1",
    "OnayTipi": "A", "OnayNum": 0
  }]
}

    Müşteri çekini portföye alma gövdesi (canlı denemede çalıştı). Tip ve CekSenEvrakKaydetmeTip ad (csMCEK, ektCekSenAlma) ya da sayı (0, 0) olabilir. Plasiyer_Kodu zorunludur (Hata 203). Gövdedeki BordroNo ve SC_NO yok sayılır, numarayı sunucu verir; yanıttaki numarayı kullanın. SC_SONDUR gövdede P verilse de tabloya B yazıldı. SC_ABORCLU, SC_BANKNO, CEK_SUBE, C_NUMARA tablo kolon adlarından türetildi (yazıldığı doğrulanmadı). Kayıt TBLCAHAR'a HAREKET_TURU = 'G' cari hareket de yazar ve REST ile silinemez.

    #E-belge

    Uç Gövde
    POST api/v2/EDocument (taslak) { "BelgeNo": "ABC2024000000123", "Tip": 1, "DizaynKontrol": false, "DovizliOlustur": false }
    POST api/v2/EDocument/SendEDocument { "DocumentNumber": "...", "CustomerCode": "...", "DocumentType": "ftSFat", "EDocumentType": 1 }
